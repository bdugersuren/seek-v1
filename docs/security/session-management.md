# Session Management

Хэрэглэгчийн идэвхтэй сесс болон нэвтрэлтийн удирдлага.

## Сессийн тодорхойлолт (Session Model)

- **IMPLEMENTED**: Сесс бүр нь хэрэглэгчийн нэг удаагийн амжилттай нэвтрэлтийн урсгалыг илэрхийлнэ.
- **IMPLEMENTED**: Сессийн өгөгдөл нь `expiresAt`, `revokedAt`, `revocationReason`, `userAgentSummary`, `ipAddressSummary` зэрэг мэдээллийг агуулж, хэт нарийвчилсан хувийн мэдээллийг хадгалахгүй (Fingerprint хийхгүй).
- **IMPLEMENTED (Session as Family)**: Тусдаа бие даасан token family байхгүй бөгөөд сесс нь (`SESSION_AS_TOKEN_FAMILY`) өөрөө refresh token-ийн гэр бүлийг холбох үүрэг гүйцэтгэнэ.

## Сесс цуцлах (Revocation)

- **IMPLEMENTED**:
  - **Гарах (Logout)**: Хэрэглэгч гарахад тухайн сессийг хүчингүй болгож (`revokedAt: new Date()`), харгалзах refresh token-ийг цуцална.
  - **Дахин ашиглалт илрэх (Reuse Detected)**: Хуучин refresh токен ашигласан үед сессийг бүхэлд нь цуцалж, түүнд хамаарах бүх токенуудыг хүчингүй болгоно.
- **FUTURE_HARDENING**:
  - Хэрэглэгчийн нууц үг солигдох эсвэл админы шийдвэрээр хэрэглэгчийн бүх идэвхтэй сессийг нэгэн зэрэг цуцлах (global logout) урсгал хэрэгжүүлэх.
  - Сессийн идэвхгүй байдлын хугацаа (Idle timeout) тооцдог болох.
