# Authentication Security

Энэхүү баримт бичиг нь seek.mn чадамжийн үнэлгээний платформын нэгдсэн нэвтрэх эрхийн зохицуулалт болон аюулгүй байдлын талаар тодорхойлно.

## Нэвтрэх зааг (Auth Boundary)

- **IMPLEMENTED**: `auth` үйлчилгээ нь хэрэглэгчийн аюулгүй байдлын данс, нууц үгийн hash болон идэвхтэй сессүүдийг удирдах бөгөөд хэрэглэгчийн нэр, утасны дугаар, академик түүх гэх мэт профайл мэдээллээс бүрэн тусгаарлагдсан байна.
- **LIMITATION**: Portal-web-ийн хамгаалалт одоогоор хөтөчийн client-side bootstrap дээр суурилж байна. Server-side middleware route enforcement нь одоогоор хэрэгжээгүй.
- **FUTURE_HARDENING**: Next.js Server-side middleware ашиглан route түвшинд нэвтрэлтийг хүчээр шалгадаг болох.

## Нууц үг хадгалалт (Password Hashing)

- **IMPLEMENTED**: Нууц үгийг хадгалахдаа `bcryptjs` алгоритмыг ашиглан hash хийнэ. Round cost factor нь `process.env.AUTH_PASSWORD_HASH_ROUNDS` (default: 10) ашиглан тохируулагддаг. Нууц үгний урт нь хамгийн багадаа 8 тэмдэгттэй байх шаардлагыг тавина.
- **IMPLEMENTED**: Платформ нь ямар ч тохиолдолд нууц үгийг түүхий болон ил хэлбэрээр лог болон өгөгдлийн санд хадгалахгүй.
- **FUTURE_HARDENING**: Argon2id алгоритм руу шилжих болон нэвтрэх үед нууц үгийг автоматаар дахин шифрлэх (rehash-on-login) шилжилтийг хийх.
