# ADR 0012: Refresh Token Rotation and Reuse Detection

## Төлөв

`PROPOSED`

## Хамгаалалт

Refresh Token хулгайд алдагдахаас сэргийлж, токенийг ашиглах бүрт шинэчлэх (rotation) болон хуучин токенийг дахин ашиглах үед илрүүлж цуцлах стратегийг хэрэглэнэ.

## Шийдвэр

- Хэрэглэгч шинэ Access Token авах хүсэлт гаргах бүрт Refresh Token-ийг rotate хийж, шинэ токен олгоно.
- Хэрэв өмнө нь ашиглагдсан эсвэл цуцлагдсан Refresh Token-оор хандвал уг токений "family"-д хамаарах тухайн сессийг (Session) тэр чигт нь цуцалж (revocation), аюулгүй байдлын сэжигтэй үйл явдлыг бүртгэнэ.
