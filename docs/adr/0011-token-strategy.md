# ADR 0011: Access and Refresh Token Strategy

## Төлөв

`PROPOSED`

## Хамгаалалт

Аюулгүй байдлыг хангах үүднээс богино хугацаатай Access Token (JWT) болон урт хугацаатай Opaque Refresh Token-ийг ашиглана.

## Шийдвэр

- Access Token-ийг JWT хэлбэрээр үүсгэнэ.
- Хөгжүүлэлт болон локал ажиллагааг хялбарчлахын тулд JWT нууцлалд symmetric гарын үсэг (HS256) эсвэл asymmetric (RS256) ашиглана. Спринт 4-ийн хувьд хялбар байдлыг бодож, одоогийн тохиргоонд суурилан symmetric `AUTH_JWT_SECRET` түлхүүрийг ашиглана.
- Refresh Token нь 64-байтын урттай санамсаргүй opaque string байх ба өгөгдлийн санд зөвхөн hash (SHA-256) хэлбэрээр хадгалагдана.
