# ADR 0014: Gateway Identity Propagation

## Төлөв

`PROPOSED`

## Хамгаалалт

Дотоод бичил үйлчилгээнүүд нь ирж буй хүсэлтийн JWT токенийг өөрсдөө баталгаажуулахгүй, харин Gateway нь токенийг нэгдсэн байдлаар шалгаж, дотоод үйлчилгээ рүү аюулгүй identity header-үүдээр дамжуулна.

## Шийдвэр

- Gateway нь ирж буй гадны хүсэлтийн Access Token-ийг шалгана.
- Хэрэв токен хүчинтэй бол дотоод сүлжээгээр хүсэлтийг дамжуулахдаа `x-user-id` болон `x-session-id` гэсэн толгой мэдээллийг (headers) нэмж дамжуулна.
- Гаднаас ирэх хүсэлтэд эдгээр дотоод identity header-үүд ирвэл Gateway тэдгээрийг шууд устгаж, хэтрүүлж бичих (overwrite) замаар identity spoofing-оос сэргийлнэ.
