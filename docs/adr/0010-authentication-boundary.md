# ADR 0010: Authentication Boundary

## Төлөв

`PROPOSED`

## Хамгаалалт

Аюулгүй байдал болон үйлчилгээний хариуцлагын заагийг тодорхой болгох үүднээс хэрэглэгчийн нэвтрэх эрх, нууц үг, сессийн мэдээллийг хэрэглэгчийн хувийн мэдээлэл (Person profile, academic history, etc.)-ээс тусад нь `auth` үйлчилгээнд хадгална.

## Шийдвэр

- `auth` үйлчилгээ нь зөвхөн `UserAccount`, `Credential`, `Session` болон `RefreshToken` объектуудыг өөрийн db-д хадгалж удирдах бөгөөд хэрэглэгчийн профайлыг үл хамааран ажиллана.
- Бусад үйлчилгээнүүд хэрэглэгчийн аюулгүй байдлын мэдээллийн сантай шууд харьцахгүй.
