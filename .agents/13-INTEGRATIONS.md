# Integrations / Гадаад системийн холболт

## DMOJ

Programming problem mapping, submission, language whitelist, judging status, compile/runtime feedback, and score mapping.

DMOJ result is evidence for `evaluation`; it never updates competency directly.

## CTFd

User/team mapping, challenge mapping, competition access, solve and score sync, integrity signals.

## Nextcloud

Collaborative documents, versioned documents, organisation workspace, and controlled sharing.

Use MinIO for platform object storage and direct uploads; use Nextcloud for collaboration.

## Adapter Rules

- least privilege;
- idempotency;
- callback signature validation;
- retry and circuit breaker;
- vendor ID mapping;
- audit;
- no vendor-specific types in core contracts.
