# Vibe Coding Agent Workflow / Vibe coding ажиллагааны дараалал

1. Read root and relevant agent docs.
2. Inspect repository, Compose profiles, contracts, migrations, tests, ADRs, and active task.
3. Write a Mongolian plan with scope, non-goals, services, files, profiles, UI, API, event, database, security, reporting, test, and rollback.
4. Ask for approval.
5. After approval update `docs/tasks/active-task.md`.
6. Implement one complete vertical slice.
7. Run approved quality checks.
8. Archive task report and reset active task.
9. Propose 2–3 next tasks.

Do not scaffold the whole platform in one uncontrolled task unless repository scaffolding itself is explicitly approved.
