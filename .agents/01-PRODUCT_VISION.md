# Product Vision / Бүтээгдэхүүний алсын хараа

`seek.mn` is a scalable competency assessment, verification, learning, commerce, reporting, and AI-assisted platform.

## Core Journeys

### Individual

```text
Register -> Verify -> Profile -> Offer -> Entitlement -> Assessment -> Result -> Competency -> Learning
```

### Employment History

```text
Add EmploymentPlacement -> Resolve ACTIVE overlap -> Save history -> Request verification
```

### Organisation Commission

```text
Request -> Scope -> Audience -> Price -> Offer -> Licence/Invitation -> Assessment -> Report
```

### High-Scale Assessment

```text
Portal launch -> short-lived code -> assessment-web -> autosave -> submit -> async evaluation -> result
```

## Principles

1. Self-service where safe.
2. Verification is graduated.
3. History is preserved.
4. Payment controls access only.
5. Runtime scales independently.
6. AI is assistive and auditable.
7. Reports disclose data quality.
8. Admins handle exceptions.
