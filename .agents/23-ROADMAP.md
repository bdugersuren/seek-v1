# Recommended Roadmap / Хөгжүүлэлтийн үе шат

1. Engineering foundation and Compose profiles.
2. `portal-web`, `assessment-web`, shared UI, mock contracts.
3. `auth`, `profile`, `organisation`, `verification`.
4. `competency`, `assessment`, `commerce`.
5. `execution`, autosave, reconnect, submit, 20,000-user load tests.
6. `evaluation`, `learning`, competency updates.
7. `reporting`, `platform`, notifications, audit, export.
8. Ollama, `ai`, prompt registry, RAG, vector search.
9. DMOJ, Nextcloud, CTFd integrations.
10. Kubernetes, autoscaling, managed data, disaster recovery, production SLOs.
