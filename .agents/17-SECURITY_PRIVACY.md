# Security and Privacy / Аюулгүй байдал ба нууцлал

## Authentication

Asymmetric JWT, refresh rotation, MFA-ready, session revocation, rate limiting, generic recovery responses, and audit.

## Authorisation

Combine RBAC, ownership, organisation scope, evaluator assignment, finance scope, entitlement, and verification policy.

## Assessment

Never expose answer keys. Preserve item versions. Use short-lived launch codes and secure cookies. Do not put long-lived tokens in URLs.

## File

Use presigned URLs, size/type validation, checksum, malware scan, private buckets, expiring downloads, and access audit.

## AI

Redact private data, defend against prompt injection, use approved sources, validate outputs, and require human review for high-impact decisions.

## Payment

Use external providers and never store raw card data.
